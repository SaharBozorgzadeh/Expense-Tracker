# Expense Tracker

A simple command-line expense tracker built with Python.

## Features

* ✓ Add expenses
* ✓ Edit expenses
* ✓ Delete expenses
* ✓ Search expenses
* ✓ Filter expenses
* ✓ View statistics
* ✓ JSON persistence

## Technologies

* Python
* JSON
* pytest
* Git

## How to Run

Clone the repository and run the main program:

```bash
git clone https://github.com/SaharBozorgzadeh/Expense-Tracker.git
cd Expense-Tracker
python Menu.py
```
